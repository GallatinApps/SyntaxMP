## Source And Attribution

SyntaxMP's tokenizers, scanners, fixtures, samples, and documentation should be
written from original work or from sources that permit the intended use.

Do not copy code, regular expressions, keyword lists, fixture text, generated
output, or sample files from another project unless the source license permits
reuse and the copied scope is documented before the change lands. When copied
or adapted material is unavoidable, include the source URL, version or commit,
license, and exact copied scope in the relevant third-party notice or source
comment.

## Development

Keep changes focused on the `syntaxmp` library boundary unless the demo app is
part of the work. The demo module is non-published and should not own public
library APIs or publication metadata.
